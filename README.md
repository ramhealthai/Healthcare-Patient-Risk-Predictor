# Healthcare Patient Risk Predictor

## Overview
Healthcare Patient Risk Predictor is a Python-based healthcare analytics project designed to evaluate patient health risk levels based on basic clinical parameters.

## Features
- Patient information input
- Age assessment
- Blood pressure analysis
- Blood sugar analysis
- Automated risk categorization
- Simple healthcare decision support

## Technologies Used
- Python 3

## Sample Input
Patient Name: John

Age: 65

Blood Pressure: 150

Blood Sugar: 200

## Sample Output
Risk Level: Critical
